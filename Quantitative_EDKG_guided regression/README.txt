Quantitative EDKG-Guided Regression

This module supports AO-driven quantitative prioritization and mechanistic interpretation. It compares predicted values across adverse outcomes (AOs) to identify the most sensitive AO or AOs for a given compound. Based on the directed causal structure of the EDKG, the identified sensitive AOs are then traced upstream to retrieve the associated key events (KEs) and molecular initiating events (MIEs), thereby reconstructing the corresponding sensitive toxicity pathways.

This stage performs AO-level comparison and graph-based mechanistic backtracking using the outputs generated by the biological entity-specific regression models. It therefore does not require an additional model-training procedure, and no separate training code is provided in this directory.

The complete quantitative prediction and mechanistic tracing workflow is directly accessible through the EDKG-DL web platform.
